CUSTOS / ENTERPRISE
B2B / ENTERPRISE

기업 AI가 도구에 접근하기 전,
조직의 권한을 확인합니다.

Custos Control Plane은 사내 AI Agent가 업무 도구와 시스템에 제출하는 구체적인 행동 요청을 조직의 정책·권한 범위와 대조하는 독립 통제 계층을 지향합니다. 통합할 경로와 고객 책임을 계약에서 개별적으로 정의합니다.

01 / ENTERPRISE USE CASES

기업 업무에서 중요한 것은
Agent가 무엇을 할 수 있느냐만이 아닙니다.

아래는 도입 가능성을 검토할 수 있는 예시입니다. 현재 고객 시스템에 연결되어 있거나 실운영이 검증된 사례를 뜻하지 않습니다.

01 / INTERNAL RETRIEVAL

허가된 내부 자료 조회

Agent가 지정된 자료 저장소에서 허용된 범위의 정보를 읽고 요약하도록 제한합니다. 조회 범위·Agent 신원·데이터 소유권을 함께 정의합니다.

02 / DRAFT & REVIEW

외부 전달 전 검토

대외 메시지나 고객 응답 초안 작성과 실제 발송을 구분합니다. 발송 같은 외부 효과는 조직 정책이 요구하는 승인과 별도 실행 경계를 거치도록 설계합니다.

03 / BOUNDED WORKFLOW

범위가 제한된 업무 자동화

허용된 행동·리소스·매개변수만 실행 대상으로 지정하고, 변경·취소·실패 처리 기준을 사전에 정의합니다.

PRODUCT BOUNDARY

Agent의 모든 행동을 통제한다고
가정하지 않습니다.

Custos는 실제로 통합되어 등록된 실행 경로를 대상으로 합니다. 고객이 원본 tool credential이나 직접 호출 경로를 유지하면 그 경로는 Custos 외부에서 실행될 수 있습니다. 통합 전 우회 경로 목록, 자격 증명 보유 위치, 네트워크 egress와 호스트 권한을 함께 검토해야 합니다.

02 / CUSTOMER ONBOARDING

기업 도입은
업무 흐름의 경계부터 시작합니다.

01 / BUSINESS OWNER

업무 소유자와 목표를 정합니다.

대상 업무, 필요한 Agent, 예상되는 도구 호출과 실패 시 업무 영향을 문서화합니다.

02 / IT & SECURITY

시스템과 보안 경계를 확인합니다.

IAM, 원본 자격 증명, API gateway, network egress, 데이터 등급, 로깅과 운영 조건을 파악합니다.

03 / PAID EVALUATION

비운영 환경에서 평가합니다.

합의된 테스트 요청에 대해 허용·차단·승인 필요 결과와 실패·만료·재시도 동작을 확인합니다.

04 / SOW & INTEGRATION

계약한 경로만 통합합니다.

SOW에 기재된 시스템, 책임자, 테스트, 보안 조치, 산출물과 검수 기준을 적용합니다.

05 / ACCEPTANCE

검수 증거와 잔여 위험을 합의합니다.

기대 판정, 승인 기록, 실행 기록, 실패 처리, 우회 점검 결과를 계약상 기준과 비교합니다.

03 / RESPONSIBILITY

고객의 정책과 최종 업무 권한은
고객 조직에 남습니다.

CUSTOS

제품과 계약 산출물

합의된 범위의 제품 구성, 통제 로직, 통합 코드·문서, 테스트 결과와 지원 조건을 제공합니다. Custos가 통제하는 것은 통합된 경로의 검증 범위입니다.

CUSTOMER

정책·데이터·권한 소유

업무 정책과 승인 기준, Agent 및 도구의 허용 범위, 데이터 접근 권한, 원본 자격 증명과 직접 호출 경로를 관리하고 최종 업무 판단을 내립니다.

INTEGRATION PARTNER

별도 위임된 변경

참여하는 경우 호스트·네트워크·커넥터 변경, 시험과 증거 수집 등 위임받은 범위만 수행합니다. 책임과 승인권자는 SOW에 지정해야 합니다.

04 / ACCEPTANCE GATES

성공 기준은 데모의 인상이 아니라
합의된 시험 결과입니다.

POLICY COVERAGE

정책 판정 정확성

허가·비허가·승인 필요 시나리오별 기대 결과와 실제 결과를 비교합니다.

APPROVAL BINDING

승인과 요청의 결합

대상 요청, 만료, 정책 변경, 재사용 시도에 따라 승인 상태가 올바르게 처리되는지 시험합니다.

BYPASS REVIEW

우회 경로 점검

Custos 외부의 원본 도구 호출·자격 증명·네트워크 경로가 남아 있는지 검토하고, 조치 주체를 명시합니다.

AUDIT & FAILURE

기록과 실패 처리

요청·판정·승인·실행 결과의 연결, 오류 시 기본 거부, 불확실한 실행 결과의 재조정 절차를 검증합니다.

검수 항목과 통과 기준은 고객 환경의 위험 분석 이후 계약에서 확정합니다. 지금 공개된 프로토타입 테스트 수치를 고객 환경의 보안 보증이나 합격률로 전환하지 않습니다.

CURRENT READINESS

현재 단계는 제한된 연구 프로토타입입니다.
기업 운영 도입을 완료한 상태가 아닙니다.

실제 고객 커넥터, 고객 운영 데이터 처리, 다중 고객 운영 격리, 직접 우회 방지, 독립 보안 감사, 침투 테스트 및 상용 SLA를 완료했다고 주장하지 않습니다. 도입 가능성은 고객별 평가와 별도 기술·보안 검토를 거쳐야 합니다.
