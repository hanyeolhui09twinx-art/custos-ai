1. 공개 웹사이트

기업 사이트 페이지는 정적 HTML·CSS·JavaScript 파일로 GitHub Pages에서 제공됩니다. 이 사이트에는 현재 광고 추적 픽셀이나 별도의 분석 SDK가 포함되어 있지 않습니다. 호스팅 제공자 GitHub는 서비스 제공과 보안 목적의 접속 로그를 처리할 수 있습니다. 자세한 사항은 GitHub의 개인정보 처리방침을 확인하세요.

2. 언어 설정

한국어·영어 선택은 브라우저 sessionStorage에 저장될 수 있으며 브라우저 세션 범위를 벗어나 영구 저장하지 않습니다.

3. Simulation Lab

기존 시뮬레이션은 브라우저 내 실험 기록을 localStorage에 저장할 수 있습니다. 이는 해당 브라우저의 로컬 저장 공간이며 사이트 운영자의 서버로 자동 전송되지 않습니다. 브라우저 설정에서 사이트 데이터를 삭제할 수 있습니다.

4. Local Control Room

Local Control Room에 입력한 Agent·Reviewer 토큰은 해당 페이지의 JavaScript 메모리에서만 사용하도록 설계되어 있으며 localStorage에 기록하지 않습니다. 콘솔은 사용자가 실행한 요청을 본인 컴퓨터의 127.0.0.1 로컬 API로 전송합니다. 실제 자격 증명이 아닌 개발용 임시 토큰만 사용하세요.

GitHub 링크 등 외부 사이트를 열면 해당 서비스의 개인정보 처리방침이 적용됩니다. Custos는 외부 서비스의 수집·처리 방식을 통제하지 않습니다.
