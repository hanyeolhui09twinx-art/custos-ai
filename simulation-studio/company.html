CUSTOS / ABOUT CUSTOS

우리가 해결하려는 문제는
AI의 실행 권한입니다.

Custos는 자율형 AI가 도구와 시스템에 접근하는 시대에, 실행 능력과 실행 권한을 분리하기 위한 독립 통제 기술을 연구하는 프로젝트입니다.

PURPOSE & PRINCIPLES

강력한 시스템일수록
권한의 경계가 명확해야 합니다.

Custos는 단순한 AI 모니터링을 넘어, 행동 요청이 실행되기 전에 독립적인 권한 판정이 이루어져야 한다는 문제에서 출발합니다.

01 / MISSION

행동과 권한을 분리

에이전트가 도구를 호출할 수 있다는 사실을 그 호출의 정당성으로 취급하지 않습니다.

02 / PRINCIPLE

인간의 최종 권한

고위험 행동에는 명시적이고 범위가 제한된 인간 승인이 필요하다는 구조를 연구합니다.

03 / METHOD

구현과 증거로 검증

정책·승인·실행 경계·감사 기록을 코드와 반복 가능한 테스트로 검토합니다.

04 / DISCLOSURE

한계와 미완성 공개

프로토타입과 상용 제품을 혼동하지 않습니다. 미구현 기능, 가정, 위험을 공개합니다.

CURRENT STATUS

현재는 독립 연구 프로젝트이며,
초기 기술 프로토타입을 개발하고 있습니다.

이 웹사이트는 프로젝트와 기술 방향을 설명하기 위한 공식 정보 사이트입니다. 법인·고객사·상용 배포·인증 또는 파트너십을 확인되지 않은 상태에서 주장하지 않습니다.

WORKING PRINCIPLES

기술적 정직성을
제품의 일부로 취급합니다.

01 / DEFINE

문제를 명확하게 정의합니다.

에이전트의 능력과 권한을 분리하고, 요청이 실행되기 전 어떤 조건을 검증해야 하는지 정의합니다.

02 / PROTOTYPE

작동 가능한 최소 통제 경계를 구현합니다.

현재 저장소에는 Python 정책 게이트웨이, 로컬 API, SQLite 승인 흐름, 모의 실행 어댑터와 감사 로그가 있습니다.

03 / VERIFY

경계 조건과 실패를 시험합니다.

자동화 테스트는 현재 구현의 특정 동작을 확인합니다. 다음 단계는 실제 에이전트와 격리된 도구 샌드박스에서 우회 가능성을 검증하는 것입니다.
