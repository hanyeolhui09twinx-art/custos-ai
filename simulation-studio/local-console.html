4. How this works

Agent request → Python policy gateway → ALLOW / HUMAN_APPROVAL / BLOCK. Approval-required requests are stored in local SQLite. A reviewer decides, then the original agent may execute the exact approved request once. Every decision is appended to the local hash-chained audit log.

This console is a thin client for the local prototype. It does not make the backend production-safe, and it does not connect to a real database, email provider, or agent tool. Stop the API server when you are finished.
