CUSTOS / RESEARCH & DEVELOPMENT

자율형 AI의 권한을
검증 가능한 문제로 바꿉니다.

Custos는 AI 에이전트가 수행할 수 있는 행동과 허가된 행동을 구분하는 기술 구조를 탐구합니다. 연구 가설, 구현 내용, 남은 문제를 구분해 공개합니다.

CORE RESEARCH QUESTIONS

에이전트의 능력과 권한은
서로 다른 시스템 속성입니다.

모델이 도구를 사용할 수 있다는 사실만으로 해당 사용이 허가되어서는 안 됩니다. 외부 정책 엔진과 실행 경계를 통해 권한을 독립적으로 확인할 수 있는지 연구합니다.

01 / AUTHORITY

권한의 최소 단위

권한은 Agent 이름 하나가 아니라 행동·대상·매개변수·시간·위임 관계에 결합되어야 하는가?

02 / DELEGATION

멀티 에이전트 위임

하위 에이전트에게 작업을 위임할 때 상위 권한을 초과하지 않도록 어떤 제약이 필요한가?

03 / HUMAN CONTROL

인간 승인과 책임

어떤 위험 기준에서 사람의 승인·거부·중단 권한이 필요하며 승인 기록은 무엇에 결합되어야 하는가?

04 / BYPASS

우회 가능성 검증

에이전트가 통제 계층을 통하지 않고 도구에 직접 접근할 수 있는 경로를 어떻게 제거할 것인가?

05 / EVIDENCE

감사 가능한 증거

누가 어떤 근거로 판정했고 실제 어떤 실행이 발생했는지 독립적으로 재구성할 수 있는가?

06 / FAILURE

실패와 복구

프로세스 충돌·네트워크 재시도·부분 성공 상황에서 중복 실행과 불확실한 결과를 어떻게 다룰 것인가?
