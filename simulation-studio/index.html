자율형 AI를 위한 독립 통제 계층

AI는 행동을 제안합니다.
Custos는 권한을 검증합니다.

에이전트의 실행 능력과 실행 권한을 분리합니다. Custos는 행동이 실행 경계에 도달하기 전에 요청을 검증하고, 정책을 적용하며, 필요한 경우 사람의 승인을 요구하는 독립 통제 계층을 연구합니다.

문제 정의

AI가 할 수 있다는 사실은
해도 된다는 뜻이 아닙니다.

자율형 AI는 도구를 호출하고, 데이터를 다루고, 다른 에이전트에게 작업을 위임할 수 있습니다. 문제는 모델의 능력만이 아니라 그 행동을 누가, 어떤 범위에서, 어떤 조건으로 허가했는지입니다. Custos는 이 권한 판정을 에이전트와 분리된 계층에서 수행하는 방식을 연구합니다.

통제 프레임워크

실행 전에 네 가지 질문을
검증합니다.

요청 주체, 권한 범위, 인간 승인, 감사 가능한 결과. Custos는 이 네 영역을 하나의 통제 흐름으로 연결하는 것을 목표로 합니다.

01 / VERIFY

누가 요청했는가

설정된 에이전트 자격 증명을 통해 요청 주체를 확인합니다. 현재 프로토타입은 로컬 정적 토큰을 사용합니다.

02 / AUTHORIZE

무엇을 해도 되는가

행동과 대상 리소스를 정책 범위와 대조합니다. 정의되지 않은 요청은 기본 거부됩니다.

03 / ACCOUNT

무엇이 실행되었는가

승인과 실행 결과를 감사 이벤트에 연결합니다. 현재 기록은 로컬 해시 연결 로그입니다.

시스템 아키텍처

통제는 모델 내부가 아니라
실행 경계에 위치합니다.

실제 서비스에서는 실행 어댑터 자체가 권한 검증을 강제해야 합니다. 현재 구현은 로컬 API와 모의 실행 어댑터까지입니다.
