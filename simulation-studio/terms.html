1. 프로젝트와 사이트의 성격

Custos AI는 자율형 AI 에이전트의 실행 권한을 독립적으로 검증하는 방법을 연구하는 초기 단계의 독립 연구 프로젝트입니다. 공개 사이트는 프로젝트 설명과 개발 현황을 제공하는 정적 웹사이트입니다. 현재 이 사이트가 상용 SaaS, 관리형 보안 서비스 또는 운영 중인 기업용 실행 통제 제품을 제공한다고 보아서는 안 됩니다.

2. 시뮬레이션 결과의 한계

Simulation Lab과 홈페이지의 정책 데모는 사전에 정한 가상 시나리오와 브라우저 로직을 사용합니다. 결과는 개념 설명과 테스트 편의를 위한 것이며 실제 AI 에이전트, 데이터베이스, 이메일, 파일 시스템 또는 외부 도구에 대한 통제 효과를 증명하지 않습니다. 데모 결과를 운영 환경의 보안 보장이나 의사결정 근거로 사용하지 마세요.

3. 로컬 Control Room 사용

Local Control Room은 사용자가 직접 실행한 로컬 Python API에 접속하는 브라우저 인터페이스입니다. API 서버와 컴퓨터, 운영체제, 브라우저 환경의 보안은 사용자가 관리해야 합니다. 임시 개발용 자격 증명만 사용하고, 운영용 비밀 키·고객 정보·실제 데이터베이스 자격 증명은 입력하지 마세요. 로컬 API를 공용 네트워크에 노출하거나 신뢰할 수 없는 도구에 연결하지 마세요.

사이트를 불법적인 목적으로 사용하거나, 타인의 시스템·계정·데이터에 무단 접근하거나, 서비스 가용성을 방해하거나, 자격 증명·개인정보·기밀 데이터를 공개하지 마세요. 시스템을 테스트할 때는 본인이 소유하거나 명시적으로 허가받은 환경만 사용하세요.

5. 지식재산 및 외부 링크

별도 표시가 없는 한 사이트의 Custos 명칭, 자체 제작 문구 및 디자인은 해당 프로젝트가 관리하는 자료입니다. GitHub 등 외부 링크는 각 제공자의 조건과 정책을 따릅니다. 외부 사이트의 가용성, 보안 또는 콘텐츠를 Custos가 보증하지 않습니다.

6. 보증 및 책임의 범위

사이트와 연구 도구는 현재 상태 그대로 연구·설명 목적으로 제공됩니다. 오류가 없거나 항상 사용 가능하다는 보장은 없으며, 특정 목적에 적합하거나 실제 환경에서 안전하다는 보장도 제공하지 않습니다. 중요한 운영·보안 결정을 내릴 때는 독립적인 검토와 자체 검증을 수행하세요. 본 안내는 적용 가능한 법률상 배제할 수 없는 권리를 제한하려는 목적이 아닙니다.
