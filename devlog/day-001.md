# Day 1 — Custos AI

## What I built

Today I started building the first prototype of Custos AI.

I implemented a basic external control gateway that evaluates autonomous AI actions before execution.

The gateway can return three decisions:

* `ALLOW`
* `BLOCK`
* `HUMAN_APPROVAL`

## What I tested

I tested three basic scenarios:

1. An authorized agent requests an allowed action.
   → `ALLOW`

2. An agent requests an action that requires human approval.
   → `HUMAN_APPROVAL`

3. An agent attempts to disable Custos.
   → `BLOCK`

## What I learned

The key idea is not simply to make an AI safer.

The control decision should exist outside the AI agent itself.

An agent can propose an action, but it should not have the final authority to decide whether that action can be executed.

## What is still missing

This is only an early prototype.

It does not yet have:

* A real LLM agent
* Real tool isolation
* Strong identity verification
* Production-level security
* Adversarial testing against real environments

## Next

Connect Custos to a real agent workflow and test whether an autonomous agent can bypass the control layer.

I want to build, test, break, learn, and improve the system continuously.
