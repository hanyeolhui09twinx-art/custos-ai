# Day 2 — Control-plane foundation

## Implemented

- Replaced the earlier minimal gateway with deny-by-default action/resource policy evaluation.
- Added strict request shape and size validation.
- Added a local HTTP API with Bearer-token-to-agent identity mapping.
- Added SQLite-backed human-approval state with expiry, reviewer decisions, requester binding, dispatch-time policy re-check, and single-use execution claim.
- Connected the gateway to the existing hash-chained JSONL audit log.
- Hardened audit append behavior to reject a broken or externally changed chain.
- Added automated gateway/API/audit tests and a GitHub Actions CI workflow.

## Current execution boundary

The only execution adapter is a mock. The "read database" and "send email" operations do not connect to a database or send messages. The API binds to loopback by default and rejects remote binding.

The hosted browser Simulation Studio remains a separate static simulation. It is not yet connected to this API.

## Security caveats

The local Bearer-token mapping is a development credential mechanism, not a complete agent identity system. The audit hash chain is tamper-evident for ordinary edits, not immutable storage. There is no distributed transaction between approvals and an external tool.
