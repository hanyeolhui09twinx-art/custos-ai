**Recorded:** 03 November 2026

## Coverage

Expanded the Chromium Playwright smoke test from the primary ten corporate routes to all fourteen public corporate routes:

- Home, Mission, Platform, Technology, Research, Security & Trust
- Company, Institutional Partnerships, Media Room, Contact
- Privacy, Terms of Use, Updates, Developer Docs

Each route is checked at nine CSS viewport widths: **320, 360, 390, 430, 768, 900, 960, 961, and 1024 pixels**. The matrix therefore covers 126 route/viewport combinations in one browser engine.

The test also verifies route responses, a single primary heading, branded page titles, the Local Control Room entry point, active navigation state, local relative links, language switching, motion-preview structure, reduced-motion fallback, and Escape-based menu dismissal with focus restoration.

## Defects found and corrected

### Tablet navigation

The prior desktop navigation remained visible until 760px, even though the header's available width was already constrained at common tablet sizes. The compact menu now activates through **960px**, before the full navigation becomes crowded. The existing 760px content-layout breakpoint remains separate.

### Media Room preview width

The motion preview combined a minimum height with an aspect ratio but did not declare its width. At narrow and tablet widths, intrinsic aspect-ratio sizing produced a box wider than its container. Setting width to 100% keeps the preview inside the content column while preserving its minimum stage height.

### Updates timeline

The indented grid timeline exceeded the available width by a few pixels at 320px. The narrow-screen timeline now uses a bounded width and zero minimum track/item widths, allowing long labels and identifiers to wrap within the page.
